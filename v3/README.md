# LBTEK — прототип главной страницы

Статический десктопный прототип сайта поставщика оптического и оптомеханического оборудования.

## Просмотр

Откройте `index.html` в браузере. Для страницы используются `styles.css` и серый логотип в `assets/lbtech-gray.svg`.

## Состав

- `index.html` — структура главной страницы
- `styles.css` — стили и адаптивное поведение
- `assets/lbtech-gray.svg` — монохромный логотип для каркаса
